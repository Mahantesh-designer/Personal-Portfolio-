A responsive personal portfolio website tailored for **Software QA / Test Automation**, **Frontend Web Development (ReactJS)**, and **Python Engineering**.

- **Personalized Content**: Exact details from Mahantesh's resume (BCA degree @ KLES's BK BCA College, academic full-stack project, certifications, technical skills).

  - **Personal Portfolio Website**: Modern responsive developer portfolio with clean UI and interactive features.
  - **QA Specialization Highlight**: Emphasizes manual testing, Selenium automation, test case design, and defect lifecycle.
- **Recruiter-Ready Resume Modal**: Interactive preview with print and "Save as PDF" functionality directly inside the browser.
- **Direct Contact & Form**:
  - One-click copy for email (`mpcreatiobgm@gmail.com`) and phone (`+91-8095450937`) with toast feedback.
  - Interactive contact form that composes an email draft directly.
- **Zero-Build Deployment**: Pure HTML5, Tailwind CSS (via CDN), custom CSS, and vanilla JavaScript. No npm build steps required!

## 🚀 How to Run Locally

You can open the website right away:
1. Double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox).
2. Alternatively, if you use VS Code, right-click `index.html` and click **"Open with Live Server"**.

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Recommended)
1. Initialize git in this directory (if not already done):
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   ```
2. Create a new repository on your GitHub account (`Mahantesh-designer/portfolio` or `Mahantesh-designer.github.io`).
3. Push your code:
   ```bash
   git remote add origin https://github.com/Mahantesh-designer/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, go to **Settings > Pages > Source**, select `main` branch and `/ (root)`, then click **Save**. Your site will be live!

### 2. Vercel or Netlify
- Drag and drop this folder onto [Netlify Drop](https://app.netlify.com/drop) or import your GitHub repository into [Vercel](https://vercel.com) for instant free hosting with custom domain support.
